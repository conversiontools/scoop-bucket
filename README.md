# Conversion Tools Scoop Bucket

Scoop bucket for [Conversion Tools](https://conversiontools.io) CLI tools.

## Install

```powershell
scoop bucket add conversiontools https://github.com/conversiontools/scoop-bucket
scoop install ctio
```

## Tools

| Tool | Description | Repo |
|------|-------------|------|
| `ctio` | Composable CLI for the Conversion Tools API | [conversiontools/ctio](https://github.com/conversiontools/ctio) |

## Update

```powershell
scoop update ctio
```
